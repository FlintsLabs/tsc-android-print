# ติดตั้งบน CipherLab RS38

CipherLab มี RS38 Android 13 ทั้ง GMS และ Non-GMS ตาม [หน้าดาวน์โหลด OS ทางการ](https://www.cipherlab.com/en/download-c2346/Android-13.html) แอปนี้ต้องใช้ Android 13 ขึ้นไป และไม่เรียก Google Play Services ต้องตรวจว่ารอมที่ใช้งานมี Android Print Spooler / Print Service รองรับด้วย ผลบน RS38 เครื่องหนึ่งไม่ยืนยันความพร้อมของรอมทุกแบบ

## ติดตั้ง APK

1. ตรวจ **Settings → About phone → Android version** ให้เป็น 13 ขึ้นไป
2. ดาวน์โหลด `TSC-Direct-Print-<version>.apk` จาก [GitHub Releases](https://github.com/FlintsLabs/tsc-android-print/releases/latest) บน RS38 หรือคัดลอกไฟล์ผ่าน USB ไปยังโฟลเดอร์ Download
3. เปิด **Settings → Apps → Special app access → Install unknown apps** เลือก Chrome หรือ Files ที่จะเปิด APK แล้วเปิด **Allow from this source** ชื่อเมนูอาจต่างกันตามเฟิร์มแวร์
4. เปิดไฟล์จาก **Files → Downloads** แล้วกด **Install**

อ้างอิงขั้นตอนอนุญาตแหล่งติดตั้งจาก [Android Help](https://support.google.com/pixelphone/answer/7391672) หากอุปกรณ์มีนโยบายองค์กร/MDM ที่ล็อกการติดตั้ง ให้ผู้ดูแลอนุญาต APK ตามนโยบายขององค์กร

## อัปเดตโดยไม่ใช้ ADB — ตั้งแต่ 1.3.4

ติดตั้ง 1.3.4 ขึ้นไปทับครั้งแรกก่อน แล้วรุ่นถัดไปใช้ **ตั้งค่า → อัปเดตแอป → ตรวจสอบอัปเดต** ได้จาก RS38 โดยตรง ดาวน์โหลด APK อนุญาตติดตั้งจาก **TSC Direct Print** กลับแอปแล้วกดติดตั้งและยืนยันใน Android ไม่ต้องถอนแอปเดิม ข้อมูลเครื่องพิมพ์/กระดาษยังอยู่ การดาวน์โหลดต้องใช้อินเทอร์เน็ตไป GitHub; หากนโยบายองค์กรล็อกการติดตั้งให้ผู้ดูแลอนุญาต ดู [วิธีอัปเดตและแก้ปัญหา](updating.md)

## เปิดการพิมพ์

1. เปิด **TSC Direct Print → ตั้งค่า** แตะชื่อเครื่องพิมพ์เพื่อเปิดหน้าตั้งค่ารายเครื่อง ใส่ชื่อ / IP เช่น `192.168.70.37` / พอร์ต 9100 / กระดาษเริ่มต้นของเครื่องนี้ แล้วกด **บันทึกเครื่องพิมพ์**
2. กด **ตรวจการเชื่อมต่อ** มือถือต้องเข้าถึงพอร์ต TCP 9100 ของเครื่องพิมพ์ผ่าน Wi-Fi/LAN ได้
3. กด **จัดการบริการพิมพ์** แล้วเปิด **TSC Direct Print** ในหน้าการพิมพ์ของ Android ปุ่มในแอปเปิดหน้าระบบให้โดยตรง
4. เลือกกระดาษ **102 × 76 มม.** หรือตามที่ใส่จริง แล้วเปิด **Print Test → พิมพ์ฉลากทดสอบ**
5. เลือก **ชื่อเครื่องพิมพ์ที่บันทึกและ IP ให้ตรงปลายทาง** ตรวจขนาดและ 1 สำเนา แล้วกดยืนยัน
6. จากนั้นใช้ Print ของเว็บไซต์หรือแอปที่รองรับ Android printing ได้ตามปกติ

หากไม่พบเมนูบริการพิมพ์ หรือไม่มี TSC ในหน้าระบบ ให้ตรวจเฟิร์มแวร์/Print Spooler กับผู้ดูแลเครื่องก่อน ไม่สามารถยืนยันความพร้อมของรอม Non-GMS จากชื่อรุ่นเพียงอย่างเดียว

## ผลตรวจ RS38 เครื่องจริง — 15 ต.ค. 2026

ตรวจพบ Android 13, `android.software.print` และ `com.android.printspooler` เปิด TSC Direct Print ได้ และเชื่อมต่อ TCP 9100 ผ่าน Wi-Fi ได้

APK 1.2.0 พบกรณีหน้าต่าง Print เริ่มด้วย Letter ชั่วคราวแล้วตัวอย่างว่างหลังเลือก TSC แก้ใน **1.2.1** โดยสร้างตัวอย่างแรกตามกระดาษที่เลือกในแอป ก่อนสร้างใหม่ตามขนาด TSC ในหน้าต่าง Print การตรวจขนาดก่อนส่งงานจริงยังอยู่

ทดสอบจากหน้า Print Test ของ APK 1.2.1 บน RS38 ไปยัง MH261T ผ่าน Wi-Fi ขนาด 102 × 76 มม. จำนวน 1 หน้า / 1 สำเนา Android รายงาน `Queued → Started → Completed` แล้ว ผู้ใช้ยืนยันว่าฉลากออก 1 ใบและขอบครบทั้ง 4 ด้าน ยังไม่ได้ยืนยันการวัดเส้น 80 มม. ในรอบนี้ APK 1.2.1 รอบนี้เป็น build ในเครื่อง ยังไม่ได้เผยแพร่ใน GitHub Releases

## หลายเครื่องพิมพ์ — 1.3.0

เพิ่มเครื่องที่ **ตั้งค่า → เพิ่มเครื่องพิมพ์** แล้วเลือกจากช่องเครื่องพิมพ์บนหน้า Print หรือ Print Test ตั้งกระดาษเริ่มต้นแยกต่อเครื่องได้ที่ **ตั้งค่า → แตะชื่อเครื่องพิมพ์ → กระดาษเริ่มต้นของเครื่องนี้ → บันทึกเครื่องพิมพ์** เมื่อสลับเครื่อง แอปจะโหลดขนาดของเครื่องนั้น หน้าต่าง Print ของ Android อาจจำเครื่องก่อนหน้า ให้ตรวจชื่อและ IP ก่อนกดยืนยันทุกครั้ง รุ่น 1.3.0 รองรับหัวพิมพ์ 203 DPI และไม่ได้ส่งหนึ่งงานไปทุกเครื่องอัตโนมัติ

## พื้นที่ขาวเหนือคีย์บอร์ด — แก้ใน 1.3.1

รุ่น 1.3.0 กันพื้นที่แถบเมนูล่างซ้ำกับคีย์บอร์ด ทำให้พื้นที่ฟอร์มหายไป 384 พิกเซลบน RS38 อัปเดตเป็น **1.3.1** เพื่อแก้การคำนวณ insets ทดสอบช่องชื่อ / IP / พอร์ตพร้อมคีย์บอร์ดจริงบน RS38 / Android 13 แล้ว
