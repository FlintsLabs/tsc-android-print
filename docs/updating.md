# อัปเดตแอปจาก GitHub

รองรับตั้งแต่ **TSC Direct Print 1.3.4** รุ่นก่อนหน้านี้ต้องติดตั้ง APK ใหม่ทับครั้งแรกผ่านไฟล์หรือ ADB ก่อน แล้วจึงใช้ปุ่มในแอปสำหรับรุ่นถัดไปได้

1. รอให้งานพิมพ์เสร็จ แล้วเปิด **ตั้งค่า** และเลื่อนลงไปที่ **อัปเดตแอป**
2. กด **ตรวจสอบอัปเดต** แอปตรวจรุ่นปกติล่าสุดจาก [GitHub Releases](https://github.com/FlintsLabs/tsc-android-print/releases/latest) เฉพาะเมื่อกดปุ่ม
3. ถ้ามีรุ่นใหม่ กด **ดาวน์โหลด <version>** รอความคืบหน้า ยกเลิกได้หากต้องการ
4. แอปตรวจ checksum และลายเซ็น หาก Android ยังไม่อนุญาต ให้กด **อนุญาตติดตั้งจากแอปนี้** แล้วเปิดสิทธิ์ให้ **TSC Direct Print** ในหน้าระบบ
5. กลับแอป กด **ติดตั้งอัปเดต <version>** และยืนยัน **อัปเดต / Update** ในหน้าต่าง Android
6. เปิดแอปอีกครั้งและตรวจเวอร์ชันในตั้งค่า ข้อมูลเครื่องพิมพ์ ขนาดกระดาษ และการเลือกเดิมยังอยู่เมื่ออัปเดตทับด้วยลายเซ็นเดิม **ไม่ต้องถอนแอปเดิม**

ชื่อเมนูและข้อจำกัดอาจต่างกันตามยี่ห้อ หากเครื่องถูกจัดการโดยองค์กร สิทธิ์ติดตั้งอาจต้องให้ผู้ดูแลเปิดให้ แอปนี้ไม่ข้ามนโยบายของเครื่อง

ภาพจาก 1.3.4 บน API 36 emulator วันที่ 15 ต.ค. 2026; ขณะตรวจ GitHub Latest ยังเป็น 1.3.3 จึงไม่เสนอให้อัปเดตลงรุ่นเก่า

## อินเทอร์เน็ตและการตรวจไฟล์

- ตรวจและดาวน์โหลดต้องเข้าถึง GitHub ผ่าน HTTPS ได้ การพิมพ์ยังส่งตรงไป IP เครื่องพิมพ์ภายใน LAN และไม่ต้องใช้อินเทอร์เน็ต
- ใช้เฉพาะ Latest stable release; ไม่เสนอ draft, prerelease, รุ่นเท่าเดิมหรือเก่ากว่า และไม่สแกน Release อื่นแทนหาก Latest มีไฟล์ไม่ครบ
- Release ต้องมี `TSC-Direct-Print-<version>.apk` และ `SHA256SUMS.txt` ชื่อไฟล์ต้องตรงกัน ดาวน์โหลดได้สูงสุด 100 MiB
- ตรวจ SHA-256 กับไฟล์ checksum และ digest ของ GitHub เมื่อมี จากนั้นตรวจ package, versionCode, versionName และ certificate ให้ตรงกับแอปที่ติดตั้ง
- เก็บ APK ในพื้นที่ส่วนตัวของแอป ไฟล์ที่ดาวน์โหลดครบแล้วสามารถตรวจซ้ำหลังปิด/เปิดแอปได้ หากดาวน์โหลดขาดให้ดาวน์โหลดใหม่ ไม่มีการดาวน์โหลดต่อจากส่วนที่ขาด
- ไม่มีการตรวจเบื้องหลัง การอัปเดตเงียบ หรือส่งเอกสาร/IP เครื่องพิมพ์ไป GitHub

## หากอัปเดตไม่ได้

| อาการ | วิธีตรวจ |
| --- | --- |
| เชื่อมต่อไม่ได้ / หมดเวลา | ตรวจอินเทอร์เน็ต Wi-Fi และวันเวลาของ Android แล้วลองตรวจใหม่ |
| GitHub จำกัดการตรวจชั่วคราว | เว้นระยะแล้วลองใหม่ ใช้ API แบบไม่ต้องล็อกอิน |
| Release ไม่มี APK/checksum ครบ | รอผู้เผยแพร่อัปโหลดไฟล์ให้ครบก่อน |
| checksum ผิด / ดาวน์โหลดไม่ครบ | ดาวน์โหลดใหม่ แอปจะลบไฟล์ที่ไม่ผ่าน |
| ลายเซ็นไม่ตรง | ใช้ APK จากผู้เผยแพร่เดียวกับแอปเดิม เช่น debug build อัปเดตทับ FlintsLabs release ไม่ได้ |
| ไม่มีปุ่มอนุญาตติดตั้ง / ถูกบล็อก | ตรวจนโยบายองค์กรหรือถามผู้ดูแลเครื่อง |
| ยกเลิกหน้าติดตั้ง / เปิดตัวติดตั้งไม่ได้ | กลับแอป ตรวจสิทธิ์ แล้วกดติดตั้งอีกครั้ง ไฟล์ที่ตรวจแล้วเก็บไว้ |
| ติดตั้งไม่สำเร็จ | ตรวจพื้นที่ว่างและข้อความจาก Android อย่าถอนแอปเดิมเพื่อแก้โดยไม่สำรองค่าก่อน |

## สำหรับผู้เผยแพร่

เพิ่ม `versionName` และ **versionCode ที่มากขึ้น** build ด้วยกุญแจเดิม และเผยแพร่ stable tag `v<major>.<minor>.<patch>` พร้อมสองไฟล์ที่สร้างจาก [build-release.sh](../scripts/build-release.sh) อย่าตั้ง Latest จนกว่าจะตรวจ APK และ checksum ครบ การ push ซอร์สอย่างเดียวไม่เผยแพร่ APK และแอปจะไม่เสนอรุ่นซอร์สที่ยังไม่มี Release

อ้างอิง: [GitHub latest Release API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release), [Android install permission](https://developer.android.com/reference/android/content/pm/PackageManager#canRequestPackageInstalls()), [FileProvider](https://developer.android.com/reference/androidx/core/content/FileProvider)
